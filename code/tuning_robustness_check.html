LPME Smoothing Selection Robustness Check

Author

Robert Zielinski

Published

May 15, 2026

The LPME algorithm uses a smoothing spline to model to obtain temporally smooth manifold estimates. Because of this, the selection of the tuning parameter \(\gamma\) serves as a key determinant of the fit of the algorithm. Our implementation of the algorithm uses leave-one-out cross-validation to select \(\gamma\) from a set of prespecified potential values, \(\exp(-15), \exp(-14), \dots, \exp(5)\) by default. In this section we seek to evaluate the stability of this smoothing selection approach. To evaluate “stability”, we follow Meng and Perez (2026) in considering whether the mapping from the smoothing parameter space to the embedding map space is continuous. Meng and Perez (2026) showed that the analogous mapping between spatial smoothing parameter \(\lambda\) and the embedding map space is continuous for principal manifolds. To assess this property in longitudinal principal manifolds, we consider an informal, empirical definition of continuity - small deviations in the value of the smoothing parameter should yield small changes in the associated embedding map, as measured by the cross-validated mean squared distance between the embedding map and the observed point cloud.

We evaluate whether this notion of continuity holds empirically, by applying LPME to simulated data. Specifically, we use the sinusoidal simulation case 1, shown in the manuscript’s Figure 2, as our test case. We generate data according to a 5-year study duration, with study visits planned every 6 months. We specify a slight linear change in the underlying manifold over time and add noise to the amplitude and period of the observed structure, ensuring that the optimal smoothing parameter value is finite, and that the choice of the smoothing parameter will contribute meaningfully to the model’s fit. We then use the LPME algorithm to estimate the longitudinal principal manifold underlying the simulated data. For each candidate smoothing value \(\gamma\), the cross-validated mean squared distance \(MSD(\gamma)\) is computed to measure the fit of the estimated embedding map to the observed data. Through this process, we obtain the optimal embedding map and its associated tuning parameter value, \(\gamma^*\), and mean squared distance, \(MSD(\gamma^*)\).

To assess the impact that a change in the tuning parameter makes, we seek to estimate the change in MSD caused by a relatively small change in \(\gamma\). For each element of the default set of values, we randomly generate a modifier, \(\delta \sim \mathcal{N}(0, 0.1^2)\). Thus, in the process of estimating the longitudinal principal manifold with tuning parameter \(\gamma^* = \exp(a^*)\), we also obtain the manifold estimate with \(\gamma' = \exp(a^* + (|a^*| \times \delta))\) as the smoothing parameter, computing \(MSD(\exp(a^* + (|a^*| \times \delta)))\) as well. Of primary interest is the relationship between \(|\delta|\) and \(MSD(\exp(a^* + (|a^*| \times \delta))) - MSD(\exp(a^*))\). From each LPME output, \(\gamma^*\), \(\delta\), \(MSD(\gamma^*)\), and \(MSD(\exp(a^* + (|a^*| \times \delta)))\) are saved, in addition to the remaining candidate values for \(\gamma\) and their associated MSD values, which provide context as to what may be considered a small change in MSD. This process is repeated for 1,000 simulation runs.

set.seed(900)

sim_data <- simulate_data(
  duration = 5,
  interval = 0.5,
  case = 1,

sim_df <- sim_data$df

sim_processed <- preprocess_data(sim_df, case = 1, d = 1, D = 2)

default_gamma <- -15:5
deltas <- rnorm(length(default_gamma), mean = 0, sd = 0.1)
gamma_vec <- c(default_gamma, default_gamma + (abs(default_gamma) * deltas))
gamma_vec <- exp(gamma_vec)

gamma_idx <- rep(seq_along(default_gamma), 2)

gamma_order <- sort(gamma_vec, index.return = TRUE)
gamma_vec <- gamma_order$x
gamma_idx <- gamma_idx[gamma_order$ix]

sim_lpme <- lpme(
  as.matrix(sim_processed$df_observed),
  d = 1,
  gamma = gamma_vec
)

n_sims <- 25

set.seed(500)

with_progress({
  p <- progressor(n_sims)

  sim_results <- foreach(
    sim_idx = seq_len(n_sims),
    .options.future = list(seed = TRUE)
  ) %dofuture%
    {
      sim_data <- simulate_data(
        duration = 5,
        interval = 0.5,
        case = 1,
        obs_noise = 0.1,
        amplitude_noise = 0.1,
        period_noise = 0.1,
        time_trend = "linear",
        time_change = 0.2,
        N = 1000
      )
      sim_df <- sim_data$df

      sim_processed <- preprocess_data(sim_df, case = 1, d = 1, D = 2)

      default_gamma <- -15:5
      deltas <- rnorm(length(default_gamma), mean = 0, sd = 0.1)
      gamma_vec <- c(
        default_gamma,
        default_gamma + (abs(default_gamma) * deltas)
      )
      gamma_vec <- exp(gamma_vec)

      gamma_idx <- rep(seq_along(default_gamma), 2)

      gamma_order <- sort(gamma_vec, index.return = TRUE)
      gamma_vec <- gamma_order$x
      gamma_idx <- gamma_idx[gamma_order$ix]

      sim_lpme <- lpme(
        as.matrix(sim_processed$df_observed),
        d = 1,
        gamma = gamma_vec,
        verbose = FALSE,
        print_plots = FALSE
      )

      opt_idx <- which.min(sim_lpme$msd)
      opt_msd <- sim_lpme$msd[opt_idx]
      opt_gamma <- gamma_vec[opt_idx]
      delta_idx <- gamma_idx[opt_idx]
      delta_val <- deltas[delta_idx]

      gamma_msds <- sim_lpme$msd[gamma_idx == delta_idx]
      mod_msd <- gamma_msds[gamma_msds != opt_msd]

      msd_diff <- mod_msd - opt_msd

      p()

      length_msd <- length(sim_lpme$msd)

      sim_mat <- cbind(
        rep(sim_idx, length_msd),
        gamma_vec[1:length_msd],
        sim_lpme$msd,
        rep(opt_gamma, length_msd),
        rep(delta_val, length_msd),
        rep(opt_msd, length_msd),
        rep(mod_msd, length_msd)
      )
      sim_mat
    }
})
